# Domain docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant architectural decisions under `docs/adr/`.
- If either location does not exist, proceed without treating its absence as an error.

## Vocabulary

Use the domain terms defined in `CONTEXT.md` in issue titles, tests, designs, and implementation. If a needed concept is missing, record the gap rather than silently introducing competing terminology.

## Architectural decisions

Surface conflicts with an existing ADR explicitly. Do not silently override a recorded decision.
