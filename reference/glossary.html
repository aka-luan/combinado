OTP glossary

Compressed terms for this course. Prefer these words in every lesson.

OTP (one-time password / code)

A short-lived secret used once to prove control of a channel (often email or phone) during login. It is not what keeps you logged in afterward.

Session secret

The credential issued after successful authentication that proves continuity of the logged-in state (cookie, refresh token, etc.). You already know this via session cookies. — NIST SP 800-63B-4

Request → verify

Two-step passwordless dance: (1) ask the server to send a code; (2) submit the code to create a session. Sending alone does not log anyone in.

TTL (time-to-live)

How long a code remains acceptable. Short TTL limits the window for guessing or inbox snooping. — OWASP MFA cheat sheet

Rate limit

Caps on how often codes can be requested or guessed. Makes brute-force of a 6-digit space impractical.

shouldCreateUser: false

Supabase option: refuse to auto-signup unknown emails on OTP request. Combinado’s closed household depends on this plus admin provisioning. — Supabase passwordless docs

Magic Link

Same underlying email auth path as OTP, but the email carries a clickable URL instead of a typed code. Combinado rejects this for in-PWA login.
